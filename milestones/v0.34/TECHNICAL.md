# Spyro: Enter the Dragonfly PSX demake — milestone 0.34

Source-derived Dragonfly Dojo three-item recovery quest. The source conversation records for Tootie, Huey and Dooie gate a single dragonfly award on three recovered items. The original motion script delays are 6, 4.5 and 6.25 seconds. The source flags are 20–23, 26–29 and 32–35, with award flag 204 (bank 1). Tootie's DFLY resource is a kite quest prop; it is not a separate free capture. The shared reward occupies project ledger slot 3; slot 2 remains reserved for Swirly. 22 original spline control points and nine placement IDs validated from the source disc.

The runtime implements proximity triggers, timed linear motion along source control points, L2 talk/return, and a one-time reward after all three returns. Diagnostic world markers: yellow = trigger, magenta = moving prop, cyan = NPC, green = returned. The HUD T/H/D indicators are grey (waiting), amber (moving), blue (arrived), green (returned); white underline means press L2. Classic and Expanded modes share this quest. Triangle switches fire/bubble; Circle breathes; R2+Start toggles mode and resets session. Original NPC models, props, dialogue text/audio, exact spline interpolation, cutscene camera and original VM execution are not implemented. Trigger range/ground checks and talk input are adapted. No emulator or physical hardware execution verified.

Native build: 462,848-byte EXE; 1,728,848 bytes linked RAM; 171,696 bytes (167.7 KiB) before reserved stack. Four new tests, six inherited bubble tests, all passed. Twelve complete quest runs cover all six completion orders in both modes, with source coordinates, timer progression while unloaded, duplicate-reward prevention, and reset. Disc EDC/ECC and fallback verified. Engineering estimate 68% (shared engine only, not campaign completion).

Build: `python tools/quest34.py <local PS2 ISO>` then `python tools/build_m34.py`; `PYTHONPATH=tools:tests python -m unittest test_m34 -v`. Use ETD_PSX_M34.cue with matching BIN. Previous ETD_BUBL.EXE is fallback. Test disc lacks Sony boot security data; authorized compatible loader needed on physical hardware.
