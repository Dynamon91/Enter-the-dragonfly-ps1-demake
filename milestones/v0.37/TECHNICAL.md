# Spyro: Enter the Dragonfly PSX demake — milestone 0.37

Lossless grouped bit packing replaces the v0.36 Spyro matrix stream and NPC pose delta arrays. Each independently byte-padded frame stores groups of four zigzag-encoded signed values with a four-bit width. Spyro retains eight-frame checkpoint intervals, predicting checkpoints from identity matrices and intermediate frames from the preceding frame. The same two matrix caches preserve blend transitions. NPCs use two cached samples per character with parity addressing (including loop wrap). No disc reads added at runtime. Bounds-aware decoder rejects truncated/overlong data and signed output overflow. Generated static banks are built locally from the earlier workspace.

All 245 Spyro frames (516 signed matrix components each) and all 36 NPC pose samples match the previously recovered integer data exactly. 1,200 randomized frame seeks/blend transitions verified. The original 18 NPC animation clips, 34 Ninja Riptoc poses, dialogue, quest progression, textures and terrain remain unchanged. No source assets were removed. This milestone does not add playable levels or new abilities.

Native MIPS-I compilation succeeded. Linked RAM 1,798,352 bytes; 102,192 bytes (99.8 KiB) before the reserved stack, a net reduction of 68,000 bytes (66.4 KiB) relative to v0.36. EXE 512,000 bytes. Six new tests and 21 inherited selected tests passed (27 total). Boot and quest texture banks unchanged. Disc sectors validated against Mode2 EDC/ECC generation. Host reference rasterizer uses new C-decoded NPC poses and original textures. Emulator boot, actual console decoder cost and frame rate remain unverified; bit packing trades extra integer decoding operations for RAM. This is not a hardware performance measurement.

Classic and Expanded modes still share the current Dojo prototype. Expanded targets remain 120 dragonflies, 26 adventure levels, four homeworlds and five bosses. Shared-engine engineering estimate 71%, not playable content completion. Controls unchanged. Next: kite animation, exact quest triggers, original voice playback, ice breath, portal transitions and boss asset recovery.
