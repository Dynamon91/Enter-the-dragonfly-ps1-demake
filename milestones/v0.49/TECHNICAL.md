# v0.49 — original voice and SFX conversion

Source-first restoration tools, plus a standalone native SPU diagnostic. The authentic v0.37 adventure remains unchanged and unavailable for rebuilding without the original disc or full generated workspace. No original audio or new compositions are included; both diagnostic tones are synthetic.

`tools/spu49.py` encodes mono 16-bit PCM at 8–44.1 kHz using five SPU predictor filters and 28-sample, 16-byte blocks. No automatic downmix/resampling; original masters must be retained. Exact aligned loops only (start aligned to 28 frames and end at EOF); one-shots end with a silent terminal block. Pack up to 512 named samples into a conservative SPU window 0x1000–0x70000 (exclusive), 454656 bytes / 444 KiB; 4 KiB reserved below, 64 KiB above. Manifest stores source SHA256, source rate, original frame count, pitch, padding and loop. `SFX49.IDX` contains little-endian magic SFX9, count, then five u32 values per sample: address, bytes, pitch, frames, loop start (FFFFFFFF for one-shot). The native API uses validated immutable resident descriptors; integration must parse the index into persistent aligned C entries. Diagnostic embeds the bank rather than reading it from CD.

Native `spu49.c` manually uploads 64-byte chunks, validates every sample header, loop flag and dummy before loading, uses bounded hardware waits and supports voice IDs 0–23. Load requires exclusive SPU initialization (all voices stopped, reverb disabled); don't call it during active music without coordination. Metadata must remain immutable while loaded. No DMA, voice allocator, streaming dialogue, or combined XA/SPU test yet. Hardware transfer completion, pitch interpolation, envelope/retrigger and loop audibility are unverified.

Build: `python tools/build49.py` (Python 3, clang MIPS-I, ld.lld, llvm-objcopy). X plays, Circle stops, Triangle selects one-shot/loop. `python -m unittest discover -s tests -p test_spu49.py -v` and `gcc -std=c99 -O2 -fsanitize=undefined -I src tests/test_bank49.c -o /tmp/bank49 && /tmp/bank49`. 10 Python tests and 9 C assertion scenarios passed; 8 previous recovery and 31 asset/XA regression tests passed. Independent FFmpeg VAG decode at mono 22050 Hz: one-shot 5600 source frames -> 5628 decoded (terminal block); loop 2800 -> 2800. PCM RMSE 49.32 and 62.45 respectively. No actual listening or hardware test. Native 16384-byte EXE linked (experimental MIPS-I warning), 300 Mode2 Form1 sectors structurally validated; disc lacks Sony security data and needs compatible emulator or authorized loader.
