# Spyro: Enter the Dragonfly PSX demake — milestone 0.36

Original Dojo NPC idle and speaking animation, and English quest dialogue. The three internal actor names Tootie, Huey and Dooie correspond to the English name IDs 429, 419 and 425 (Rusty, RJ and Dougy) in TITLE.CNK record 83. LANG_SEL contains a second English table with punctuation differences; TITLE is selected for this build. The original scripts' Say IDs are validated against 18 source strings (including names), with wrapping but no rewriting. Conversation presentation selects greeting, help, return, other-dragon and reward/revisit text based on the v0.34 quest state. L2 near an NPC opens the modal conversation; L2 or Cross advances. Gameplay simulation pauses while the panel is active; Start resets as before. The original automatic Grab conversation trigger, camera motion, voice playback and debug shortcut flags are not implemented. The reward remains granted at quest interaction time, not at the end of its original voiced cutscene. Ice breath and exact environmental puzzle triggers remain pending.

Recovered six animation clips per baby dragon (18 uniquely matched payloads, 10,824 keyframes) and 30 joints per model. The original idle/talk clips are sampled at six poses each, 36 poses total; fixed-point interpolation blends adjacent samples at the nominal 30 updates/s. Vertex clustering exactly matches v0.35 bind meshes; signed byte deltas preserve each baked integer pose exactly. Skinning uses recovered weights, hierarchy checked against bind translations, provisional Euler order/scale channels and root translation suppression. Facial objects are rigidly attached to head. Kite rest geometry retained; its original animation remains pending. Host reference preview uses recovered source geometry and palettes, not emulator capture. Subtitle panel uses an independent DejaVu-derived bitmap font (not original font) and simple rectangular pixel runs, with no extra texture VRAM. Actual GPU costs and physical output not measured.

Native MIPS-I build ETD_TALK.EXE: 587,776 bytes. Linked RAM 1,866,352 bytes (1.78 MiB), 34,192 bytes (33.4 KiB) before reserved stack. All 6 new and 15 inherited selected host tests passed (21 distinct tests), including source ID mapping, pose reconstruction, all twelve quest completion order/mode scenarios, bubble capture, dialogue branch/bounds checks, disc ECC/EDC and bank integrity. No additional geometry or texture reductions; QMOD35.DAT and BOOT32.DAT unchanged. Further memory optimization recommended before larger content additions. Emulator boot, voice, actual framerate and real hardware remain unverified.

Classic and Expanded modes share the Dojo prototype. Expanded target: 120 dragonflies, 26 adventure levels, four homeworlds, five major bosses. New levels and bosses are planned, not implemented. Shared-engine engineering estimate 70%, not playable campaign completion. Controls: Triangle switches fire/bubble; Circle breathes; L2 opens dialogue; L2/Cross advances; R2+Start toggles campaign mode and resets session. Existing sector, combat, capture and quest logic retained.

Build from full local workspace: `PYTHONPATH=tools python tools/questanim36.py <local PS2 ISO>`; `PYTHONPATH=tools python tools/dialogue36.py <local PS2 ISO>`; `python tools/build_m36.py`; `PYTHONPATH=tools:tests python -m unittest test_m36.M36 test_m35.M35 test_m34.M34 test_m33.M33 -v`. Open ETD_PSX_M36.cue with matching BIN. ETD_NPCS.EXE fallback on disc. Real hardware requires authorized compatible loader; no Sony boot security data. Public source repository excludes original PS2 ISO and generated proprietary asset banks, including generated dialogue/pose headers.
