# v0.41 — native arena collision workprint

Additive, original fan-designed top-down test arena, not the recovered PS2 boss arenas or a full adventure disc. Five selectable encounters: Crush shockwave, Gulp projectile volleys, Ripto three-element phases, Gnasty charge, final alliance combined charge/projectile proxy (one actor, not two). This test does not mutate the campaign ledger; SELECT freely cycles encounters for testing. Win flags persist within the session, START retries. D-pad moves, SQUARE accelerates, TRIANGLE cycles elements, CIRCLE breathes in the facing direction. Player has four HP, temporary invulnerability after hits; boss contact, moving projectiles and slam hazards cause damage. Timing, HP, artwork and elemental rules for new bosses are provisional. GPU renderer uses double buffering and an IRQ completion fence, not measured on hardware. Nominal 30 ticks/s in NTSC. No 3D models or original assets in this diagnostic.

Build from root with `python tools/build41.py` (clang, ld.lld, llvm-objcopy); output `out41/ETD41.EXE`, `ETD41.bin`, `ETD41.cue`. Build reuses the v0.40 controller and GPU helper prefix, start code, linker script and disc16 encoder. For host tests: `gcc -std=c99 -O2 -fsanitize=undefined,address -I src tests/test_arena41.c -o /tmp/a41 && /tmp/a41 /tmp/arena41.ppm`. PPM is a host-rendered frame from the same renderer, not emulator capture. Five bosses defeated using input-only deterministic bot (192/377/1143/566/338 ticks); checks for movement bounds, direction, element mismatch, hit, invulnerability, loss, and reset. Prior 13+4+8 scenario groups passed. 300 Mode2 Form1 sectors structurally validated. Linked MIPS-I, entry 0x80010000, 16,384-byte EXE. No emulator or physical console available; GPU/controller behavior and real timing unverified. Disc lacks Sony security data; physical console requires compatible authorized homebrew loader. Full v0.37 generated asset workspace still absent, so full adventure cannot be linked.
