# v0.44 — workprint asset library

Additive revision on v0.43. Nine newly authored low-poly models (597 indexed vertices, 845 triangles, 20 flat material colors): Spyro, Crush, Gulp, Ripto, Gnasty Gnorc, dragonfly, tree, ice crystal and portal. These are fan-made prototype meshes, not extracted PS2 assets. `assets44/models.json` is the editable procedural source; `assets44/obj/` contains actual Wavefront OBJ files and shared MTL, and `assets44/manifest.json` records geometry counts and SHA256 hashes. `tools/assets44.py` exports the OBJ/MTL and generates `src/models44.h` (signed-byte local coordinates, byte indices, animation group per vertex). `tools/integrate44.py` creates new renderer headers and the derived frame test without replacing earlier versions. The executable uses these new meshes, integer face lighting, four cardinal headings and simple eight-step wing deformation. Trees/crystals and a decorative portal appear in test rooms. The alliance has two visible characters but still uses one combat state machine and collider. The portal is decorative; destination selection is still menu driven. Existing synthetic level layouts, player physics, progression and combat rules are unchanged. No UV textures, skeletal animation, original music or recovered v0.37 scene banks in this revision.

Build from repository root: `python tools/build44.py` (Python 3, clang MIPS-I, ld.lld, llvm-objcopy). Output `out44/ETD44.EXE`, `ETD44.bin`, `ETD44.cue`. The build regenerates asset arrays and renderer derivatives. Host check: `gcc -std=c99 -O2 -fsanitize=undefined -I src tests/test_assets44.c -o /tmp/a44 && /tmp/a44 /tmp/room44.ppm /tmp/boss44.ppm`. All nine models passed face/index/material and nondegeneracy tests. 510 arena frames plus 280 additional campaign/boss asset frames passed, peak 670 submitted triangles, no overflow. Previous campaign simulation reached 120 captures, 30 locations and all five boss victories; prior v0.38–v0.43 host regression suite passed. Native MIPS-I linked, 38912-byte PS-X EXE; ELF text 35853 bytes, data 8 bytes, BSS 24588 bytes. 300 Mode2 Form1 sectors validated structurally. Emulator boot, PS1 GPU output, controller behavior and actual framerate remain unverified. Disc lacks Sony security data; use an emulator or compatible authorized loader. Current build is an asset-integrated campaign diagnostic, not the restored original adventure. Host previews are rendered by the same mesh renderer, not emulator screenshots.
