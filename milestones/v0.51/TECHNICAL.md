# Classic v0.51 — source-derived level streaming

Classic-only milestone. Expanded Mode remains frozen. The original v0.37 hub and Dojo gameplay source is unchanged. This is an offline bank packer, not a new playable PS1 disc or new recovered level.

`tools/classic_sector51.py` packs reviewed source world geometry, collision triangles and object placements into the existing ETDS v1/ETDI v1 format. The input geometry NPZ contains vertices, faces, UVs and per-face source material hashes (as in classic_mesh50). Collision NPZ requires vertices, faces and per-face flags (0 or 3); for v0.25 collision files derive flags from polygon_flags[part] after review. Config JSON includes a standalone Classic bank ID (0–8 released scenes, 9 Ripto arena, not the Expanded campaign ID), world_coordinates_reviewed:true, materials list of {id,hash,status:"resolved"} and objects list of {kind,value,source_id,source_xyz}. Resolve and review materials, world transforms, collision and placements independently before running; the flags are caller attestations, not verified authenticity. The original source must be retained locally.

    python tools/classic_sector51.py geometry.npz collision.npz reviewed_config.json new_level_bank
    python -m unittest discover -s tests -p 'test_classic*py' -v

Python 3, NumPy and GCC required for host tests. The packer converts source Y-up to runtime Y-down as in v0.25, rounds coordinates within 0.5 source units, quantizes UVs to Q10 (integer repeat shifts only when necessary), preserves render/collision face array IDs and source placement IDs, uses centroid-owned 2048-unit cells with full geometry AABBs, emits 2048-byte aligned blocks <=65536 bytes, per-block CRC32 and whole-file SHA256. It rejects bad indices, unresolved material IDs, unsupported collision flags, duplicate placements, coordinate overflow, collapsed triangles and UV ranges that cannot be represented. A sweep computes exact worst-case neighborhood bytes and block counts at 512-unit grid anchors for radius 1792, using full AABBs and sector-rounded sizes. This is an analysis metric, not a measured runtime budget or cache certification. Banks are not automatically mounted: v0.37 still assumes Dojo-specific counts, names, spawn, quest data and cache limits. New materials need matching texture banks; no actual texture conversion or collision/placement reconstruction was performed here.

14 new host tests and 10 inherited mesh-recovery tests passed. The original repository src/sector27.c (Git blob 73c0b1e8f5ff1219f9c29beb3ab8ec6ece401aff) compiled as a shared host library and loaded all test bank blocks via its original read callback. A 4000-face synthetic stress fixture retained every render ID; corrupted data rejected without publishing metadata. Peak calculation matched brute-force fixture enumeration. The same original reader compiled for MIPS-I (3352 text bytes, zero data/BSS; compiler warns experimental MIPS-I support). This is an object compile, not a complete executable or hardware test. All fixture geometry is synthetic and only used in tests; no fallback geometry inserted into authentic content. No original disc or complete v0.37 workspace was available. No emulator run.
