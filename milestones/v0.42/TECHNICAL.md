# v0.42 — perspective 3D combat workprint

Additive native PS1 diagnostic based on v0.41. Does not replace the v0.37 adventure, whose generated source asset banks remain unavailable in the current workspace. No original PS2 models, textures, soundtrack or maps were added. The five v0.41 combat state machines and inputs are unchanged: SELECT cycles encounters; START retries; D-pad moves; SQUARE charges; TRIANGLE switches element; CIRCLE breathes. The final alliance still uses a single actor. The camera is fixed, not a follow camera.

`src/view42.h` constructs original low-poly 3D geometry (dragon, boss proxy, floor, pillars, rails, projectiles, elemental breath and shockwave) and projects it via integer perspective on the CPU. The GPU receives flat-shaded triangles. Floor triangles are drawn first, other triangles sorted far-to-near by centroid depth; this is approximate painter ordering, not a depth buffer, GTE pipeline, or general near-plane clipping. The arena bounds keep the denominator positive; the projected model can extend outside the viewport and GPU drawing bounds clip it. The native diagnostic retains double-buffered GPU page flips from v0.41. HUD preserves player/boss health, boss selection/victory, selected breath, exposure window and Ripto shield/phase. The original artwork and animations must be recovered separately.

Build with `python tools/build42.py` (clang, ld.lld, llvm-objcopy). Output out42/ETD42.EXE, ETD42.bin and ETD42.cue. `gcc -std=c99 -O2 -fsanitize=undefined,address -I src tests/test_view42.c -o /tmp/view42 && /tmp/view42 /tmp/view42.ppm` renders a host reference frame and checks 510 frames, including all five encounter IDs, all four directions, all corner positions, six simultaneous projectiles and attack/breath effects. Peak 437 submitted triangles across floor and model passes; zero buffer overflow, nondegenerate triangles, bounded projections and sorted model depth. Prior v0.38, v0.39, v0.40 and v0.41 tests all pass (13+4+8 scenario groups, plus five input-driven boss victories and collision checks). No frame timing measurement. Native MIPS-I linking passed (compiler warns experimental support); 24,576-byte PS-X EXE, entry 0x80010000, stack 0x801fff00. 300 Mode2 Form1 sectors structurally checked. No PS1 emulator executable installed; actual GPU rasterization, controller input and hardware performance remain unverified. Disc lacks Sony security data; real hardware requires a compatible authorized loader.
