# Spyro: Enter the Dragonfly PSX demake — milestone 0.35

Original Dojo quest actor models replace diagnostic world markers. EDF conversation links identify Tootie as BABY_DRAGON_C.MRB, Huey as BABY_DRAGON_B.MRB, and Dooie as BABY_DRAGON_A.MRB. All three moving prop definitions, including the decoder quest, reference KITE.MRB. Metadata hashes resolve uniquely to records 97, 553, 1022 and 419; original geometry packets 353, 117, 105 and 311 pass per-shape packet count and bounding-box checks. Recovered 4,472 source render triangles; 3,571 retained after position clustering/deduplication. Six original eyeball meshes, eyebrows/lashes where present, wings and body geometry, and kite tail, ribbons and string retained. Eleven original 64x64 indexed texture groups converted to 8-bit CLUT with opaque palette semantics. Head-local facial mesh translation recovered from bind matrices. NPCs face the player using reconstructed yaw; static bind poses, kite orientation and source PS2 shader/blending remain provisional. The moving kite follows the v0.34 path, and its idle position now uses the original prop placement instead of the trigger. No separate decoder book substituted; the source references the kite model.

Native PS1 MIPS-I build: ETD_NPCS.EXE 528,384 bytes; linked RAM 1,805,088 bytes (1.72 MiB), 95,456 bytes (93.2 KiB) before reserved stack. A separate 50,688-byte QMOD35.DAT texture bank is CRC-checked and uploaded from the sector arena before reuse. 11 texture slots + 11 CLUT rows fit in unused VRAM; no overlap with framebuffers, terrain, Spyro, sky, Ninja or fire. Original BOOT32.DAT unchanged for the v0.34 fallback. Five new host tests plus ten inherited quest/capture tests passed (15 distinct tests). All twelve quest order/mode scenarios still pass. Disc sector ECC/EDC checked. No emulator boot or hardware verification; texture filtering/lighting and ordering artifacts may remain. NPC animation, original dialogue and camera, exact kite transform/animation and portal transitions are unfinished. The preview is a software rasterization of recovered meshes, not emulator output.

Classic and Expanded modes retain shared Dojo gameplay; Expanded target: 120 dragonflies, 26 adventure levels, four homeworlds, five bosses, all unimplemented expansion content clearly distinguished from recovered originals. Shared-engine engineering estimate 69%, not campaign completion. Controls unchanged: Triangle switches breath, Circle breathes, L2 near NPC, R2+Start switches mode and resets. World quest markers removed; HUD remains diagnostic.

Build from complete local workspace: `python tools/questmodels35.py <local PS2 ISO>` then `python tools/build_m35.py`; `PYTHONPATH=tools:tests python -m unittest test_m35.M35 test_m34.M34 test_m33.M33 -v`. Open ETD_PSX_M35.cue with matching BIN; ETD_QEST.EXE is the fallback. Disc does not contain Sony boot security data; an authorized compatible loader is needed on real hardware. Public source repository excludes generated proprietary asset banks and original PS2 ISO.
